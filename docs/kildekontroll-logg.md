# Kildekontroll-logg

Sporer når hver innholdsfil sist ble verifisert fag-for-fag mot sin siterte
primærkilde (ikke bare sjekket for *nye* retningslinjeversjoner — det gjør den
årlige rutinen separat — men om teksten fortsatt stemmer med kilden slik den
allerede foreligger).

Brukes av den kvartalsvise automatiserte kildeverifiseringen
(scheduled task "Uro Info – kvartalsvis kildeverifisering"): hver kjøring plukker
de ~15 filene med eldst dato (eller uten dato) nedenfor, verifiserer sitert
fakta mot kilden, oppretter PR ved avvik, og oppdaterer datoene under for de
filene som ble sjekket. Full runde gjennom alle filene tar da omtrent 2 år.
